# Weather Aggregator & CLI Tool

Скрипт на Python для параллельной загрузки погодных данных по списку городов через API [wttr.in](https://wttr.in/), группировки результатов по странам, вывода статистики в консоль и сохранения итогов в формате JSON.

---

## 🛠 Какие библиотеки использованы и для чего?

Проект разработан **исключительно на стандартной библиотеке Python 3** без использования внешних зависимостей (`pip install` не требуется):

* **`dataclasses`** (`@dataclass`): Для удобного объявления модели данных `WeatherData`.
* **`urllib.request` / `urllib.error` / `urllib.parse`**: Для отправки HTTP GET запросов к REST API и кодирования URL.
* **`json`**: Для парсинга ответов от API и экспорта итоговой статистики в JSON-файл.
* **`concurrent.futures`** (`ThreadPoolExecutor`): Для реализации многопоточной загрузки данных.
* **`sys`**: Для считывания аргументов командной строки (пути к файлу).
* **`typing`**: Для строгой аннотации типов параметров и возвращаемых значений.

---

## ⚡ Использование многопоточности

Загрузка данных о погоде выполняются параллельно с помощью пул-исполнителя `concurrent.futures.ThreadPoolExecutor`. 

Поскольку операции сетевого запроса относятся к категории **I/O-bound** (ожидание ответа от сервера), использование 5 параллельных рабочих потоков (`NUM_WORKERS = 5`) позволяет сократить суммарное время выполнения программы в несколько раз по сравнению с последовательными запросами.

## 🚀 Как запустить код?

### 1. Подготовка файла со списком городов
Создайте текстовый файл (например, `cities.txt`) и укажите города по одному на строку:

```text
Tokyo
London
Osaka
Kyoto
Manchester
```

### 2. Запуск скрипта

Передайте путь к файлу с городами в качестве аргумента командной строки:

```bash
python script.py cities.txt

```
